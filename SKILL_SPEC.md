# Skill Specification

Each skill is a directory containing `SKILL.md` and, where relevant, tests or fixtures.

Required sections:

- Purpose and scope
- Triggers and prerequisites
- Concepts and decision criteria
- Procedure
- Examples and counterexamples
- Failure modes and recovery
- Validation evidence and provenance
- Confidence, freshness, lifecycle, and review trigger
- Related skills and conflicts

Lifecycle: `discovered → researched → draft → reviewed → validated → trusted`; `experimental` may branch from any pre-trusted state; `deprecated` records invalid or superseded knowledge.
